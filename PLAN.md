# The plan

No dates. An order, sizes, and gates. Work through it top to bottom; the parallel tracks never stop.

## Why this order

Airbus reviews apprenticeship applications months before the start date, and the Skywise postings all ask for the same core: **Python, PySpark, SQL, Palantir Foundry** (Code Repositories, Pipeline Builder, Ontology, Workshop, Quiver…), then data science and GenAI. So the plan front-loads exactly that, and makes Aerolisa **demoable from the first milestone** so that the link on my CV is always worth clicking.

1. **Phase A, Application-ready:** Python, SQL, modeling, PySpark, quality, Foundry. The skills on every Skywise posting.
2. **Phase B, Interview-ready:** statistics, ML, predictive maintenance. The skills that make me memorable for data scientist and AI roles, and the heart of Aerolisa.
3. **Phase C, Complete profile:** BI, engineering/MLOps, GenAI. What turns a good apprentice candidate into a junior people want to keep.

I already use Power BI and Excel daily at ALTEN and did C-MAPSS research at CESI (SAA project). The plan takes that into account: BI comes late, and the first Aerolisa milestone reuses my existing predictive maintenance work.

## The gates

**Gate 1: Application-ready**
- [ ] CV (EN + FR) and LinkedIn updated with Aerolisa and Foundry work
- [ ] Aerolisa M1 live: public demo link, README with GIF and results
- [ ] Aerolisa M2–M3: data platform with Foundry-style transforms, quality checks, ontology
- [ ] Aerolisa M4: Foundry edition built on the Developer Tier, screenshots + short video
- [ ] Exit tests 00–07 passed (≥ 80%)
- [ ] Applications going out (see [career/](career/README.md))

**Gate 2: Interview-ready**
- [ ] Aerolisa M5–M7: real flight cycles, engine health v2 with uncertainty, planner + operational app
- [ ] Exit tests 08–10 passed
- [ ] 5 STAR stories and the "why Airbus / why Skywise" answer recorded and reviewed
- [ ] One full mock interview done (video + technical)

**Gate 3: Complete profile**
- [ ] Aerolisa M8–M10: analytics pack, Docker + CI/CD, copilot with evaluation
- [ ] Exit tests 11–13 passed
- [ ] Aerolisa M11: 3-minute demo video, case study, portfolio page

## When I fall behind

1. Drop every unfinished 🚀 Pro item first.
2. If still behind, shrink the Aerolisa milestone to its "done when" line and ship that.
3. Never skip a gate check; move it, then do it.
4. Two weekends in a row with energy ≤ 2 in the weekly review: next weekend is a floor weekend (one session, one commit).

## When I get ahead

Do the 🚀 Pro level of the module just finished, in this priority: Foundry (06–07) → PySpark (04) → ML (09–10) → everything else.
