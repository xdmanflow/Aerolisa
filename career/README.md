## The pipeline

```text
watch postings → tailor CV → apply → recruiter review → pre-recorded video interview
→ manager / tutor interviews → offer → CESI + HR paperwork → contract signed
```

| Stage | What decides it | My lever |
|---|---|---|
| Recruiter review | Keywords match, proof, clean CV, right duration and start date | Tailored CV, Aerolisa link, Foundry work |
| Video interview | Clarity, motivation, structure, English/French | Rehearsed pitches and STAR stories, recorded practice |
| Manager interview | Technical depth, curiosity, team fit, domain sense | Question bank, Aerolisa walkthrough, questions about the team |
| Offer → contract | Admin readiness | RNCP code, CESI calendar, paperwork started early |

## Targets, in order

1. **Airbus, Skywise ecosystem, Toulouse.** Any data posting that uses Skywise: data engineer, data analyst, data scientist, data app developer, AI. Across Airbus Commercial Aircraft, Airbus Operations SAS, Airbus SAS (corporate functions), Airbus Atlantic, ATR.
2. **Airbus, other data/AI postings in Toulouse,** including Defence and Space (many require eligibility for a French security clearance: read each posting).
3. **Other ASD companies in Toulouse and France** with data/AI apprenticeships: see [asd-industry.md](asd-industry.md).
4. **The Skywise consultancy route:** engineering and IT consultancies that staff Skywise/Foundry projects for Airbus (ALTEN and Capgemini both recruit for it). A fallback that still builds Foundry experience on Airbus data.

## Rules

- **Apply the same week** a matching posting appears; good apprenticeships close early.
- **Duration filter:** my programme's final year is the alternance year, so prefer postings whose duration includes one year ("1 an", "1 à 3 ans"). If a posting asks for 2–3 years, apply anyway and say clearly what CESI allows.
- **60–70% match is enough to apply.**
- **One tailored CV per application,** never a generic one.
- **Log everything** in [applications.md](applications.md), including rejections and what I learned.
