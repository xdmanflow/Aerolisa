# Airbus & Skywise knowledge pack

Facts below were checked against Airbus public pages and Airbus postings in late 2026. Anything marked *(check)* must be re-verified before an interview; things change.

## Identity

- **Purpose:** "We pioneer sustainable aerospace for a safe and united world."
- **Six values:** Customer focus, Integrity, Respect, Creativity, Reliability, Teamwork. Chosen through a company-wide process with tens of thousands of employees. Prepare one personal example per value (they map well onto STAR stories).
- **Divisions:** Airbus Commercial Aircraft, Airbus Defence and Space, Airbus Helicopters.
- **Toulouse sites named in postings:** Blagnac (incl. Wings Campus), Saint-Martin-du-Touch, the Jean-Luc Lagardère site. Know which site a posting is on before the interview.
- **Postings mention compliance awareness and acting with integrity** in almost every description: expect a question on ethics or confidentiality.

## Skywise

- **What it is:** Airbus's aviation data platform, launched in 2017 and developed with Palantir; built on Palantir Foundry (a Spark-based big data framework). Airlines, MROs and Airbus teams use it.
- **Scale (Airbus page):** more than 12,300 aircraft connected *(check: the number grows)*.
- **Entry level: Skywise Core** (Core X3 is mentioned in recent airline agreements) *(check)*.
- **Fleet performance products,** grouped as **S.Fleet Performance+ (S.FP+)**, covering three domains:
  - **S.Health Monitoring:** real-time aircraft events (live diagnostic feeds via ACARS) to help line maintenance, the Maintenance Control Centre and engineering identify, prioritise and handle in-service events.
  - **S.Predictive Maintenance+:** early alerts on upcoming system degradation, so unscheduled events become scheduled ones.
  - **S.Fleet Reliability:** integrates reliability data, benchmarks fleet performance against the worldwide Airbus fleet, identifies root causes.
- **Quiver** has been used by airlines on Skywise to analyse large-scale sensor data for flight-ops analysis, predictive maintenance and troubleshooting.
- **Inside Airbus,** Skywise is the big data platform for engineering, manufacturing, quality, customer services, supply chain and corporate functions. Many apprenticeship postings say "the favoured development platform will be Skywise".

How Aerolisa maps onto these: [Aerolisa docs/skywise-foundry-mapping.md](https://github.com/xdmanflow/Aerolisa/blob/main/docs/skywise-foundry-mapping.md).

## What data apprenticeships at Airbus look like

Titles seen in 2025–2026 Toulouse postings (to calibrate, not to memorise):
- Data analyst & Skywise development (airframe integration): collect engineering data, build interactive dashboards in Skywise, technical support
- Data scientist, customer care centre: use Skywise data, apply data science on operational use cases
- Data scientist & digital transformation, in-service engineering: Skywise use and development, user support and training
- Data analyst, risk management: performance follow-up integrated into Skywise
- Data application developer (Airbus Atlantic): PySpark or SQL in Foundry to clean and transform SAP data, Python pipelines and APIs between SAP/Skywise and the user interface
- Data analyst, strategic communication & PMO: collect data from big data sources (Skywise), harmonise KPI dashboards (Skywise, Google Sheets)
- Skywise UX/UI designer; AI integration & enterprise architecture; data scientist / AI engineer, LLMs for space engineering (Defence and Space, security clearance eligibility required)

**Recurring requirements:** Python, PySpark, SQL; Foundry tools (Code Repository, Pipeline Builder, Ontology, Object Explorer, Workshop, Quiver, Slate, Contour, Marketplace, templates, access management); TypeScript for app logic; data modeling; machine learning (linear regression, random forest, gradient boosting); dashboards; English B2+/fluent and French; curiosity and fast learning of new platforms ("no prior Foundry experience required" appears often, which means prior experience stands out).

**Other tools seen next to Skywise:** SAP, SAP Analytics Cloud, Qlik Sense, Qualtrics, Salesforce, Google Workspace (Sheets, Sites).

## Selection process (as written in recent apprenticeship postings)

1. A recruiter reviews the application.
2. If retained: a **pre-recorded video interview**.
3. If shortlisted: **interviews with the manager / tutor**, then the final choice.

The application form asks for information about the school programme, including its **RNCP code**. Have it, the CESI alternance calendar, and the possible start date ready before clicking "apply".

## Languages in postings
English from "B2 / professional" to "negotiation / fluent", French from intermediate to fluent depending on the team; German "a plus" for some roles. See [languages.md](languages.md).

## Beyond Toulouse (for later mobility)
Foundry/Skywise roles also appear at Airbus in Copenhagen, Albacete (a "Core Digital Campus" hiring Foundry data engineers), Bangalore, and Atlanta (aviation data & analytics). Internal mobility is one of the most realistic routes to Spain, other countries, or the US later.

## To research myself before each interview
- [ ] The department code and what it does (postings use codes like "1S", "1ALV")
- [ ] People in that team on LinkedIn: roles, tools they mention, how long they've been there
- [ ] Recent Airbus news for that programme or product
- [ ] Whether the team builds on Skywise, consumes Skywise dashboards, or both
