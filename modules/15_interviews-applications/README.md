# Module 15 · Interviews & applications

**Roles:** all · **Size:** parallel track (≈ 1 h/week) + 2 dedicated weekends + every Saturday before an interview · **Priority:** P0 · **Builds:** Aerolisa M11 (showcase)

## Why this matters
Skills that aren't shown don't get hired. Airbus apprenticeship selection, as described in recent postings: a recruiter reviews the application → a **pre-recorded video interview** → if shortlisted, **interviews with the manager/tutor**. Each stage filters on different things: CV keywords and proof, then clarity and motivation on video, then technical depth and team fit with the manager.

All supporting material lives in [career/](../../career/README.md).

## 🎯 Apprenticeship level (must)
- [ ] Application pipeline running: saved searches, tracker, one tailored application per matching posting
- [ ] CV tailored per posting in < 20 minutes (keywords from the posting, proof links)
- [ ] 5 STAR stories written and rehearsed ([career/stories.md](../../career/stories.md))
- [ ] "Tell me about yourself", "why Airbus", "why Skywise / data", "why this team" answers, 60–90 s each ([career/pitches.md](../../career/pitches.md))
- [ ] Aerolisa explained in 30 s, 2 min and 5 min versions
- [ ] Technical question bank answered in my own words ([career/interview-bank.md](../../career/interview-bank.md))
- [ ] Video interview practice: 10 recorded answers, rewatched, improved
- [ ] One full mock interview with a real person (classmate, ALTEN colleague, CESI career service)
- [ ] 3 good questions to ask each interviewer
- [ ] Follow-up and thank-you emails within 24 h
- [ ] Contract knowledge: alternance rhythm, pay rules, what to check before signing ([career/apprenticeship-pay-and-contract.md](../../career/apprenticeship-pay-and-contract.md))

## 🚀 Pro level
- [ ] Informational chats with 5 people working on Skywise / Foundry (LinkedIn), notes kept
- [ ] One LinkedIn post per Aerolisa milestone
- [ ] Portfolio page (GitHub Pages) linking everything

## Steps
**Every week (parallel)**
1. Check saved searches (careers.airbus.com and the other targets in [career/asd-industry.md](../../career/asd-industry.md)); apply the same week a matching posting appears.
2. Update [career/applications.md](../../career/applications.md).
3. Commute: say one pitch or one STAR story out loud.

**Dedicated weekend 1 (after Gate 1)**
4. Write the 5 STAR stories and the 4 pitches; record them on video; rewatch; rewrite.
5. Answer the Python, SQL, data modeling and Foundry parts of the question bank on paper.

**Dedicated weekend 2 (after Gate 2)**
6. Answer the statistics, ML and predictive maintenance parts of the question bank.
7. Full mock: 5 video answers + a 30-minute technical (one SQL problem, one Python problem, explain Aerolisa, one ML question).

**Before every interview (replaces that Saturday's module session)**
8. Research the team: posting wording, department, people on LinkedIn, recent Airbus news for that programme.
9. Map the posting's requirements to my proof (one line each). Prepare 3 questions.
10. Rehearse the three Aerolisa lengths and the stories most relevant to that posting.

## Exit test
Full mock interview recorded: 5 video-style answers + 15-minute technical. Rewatch with the checklist in [career/interview-bank.md](../../career/interview-bank.md); score ≥ 80%.
