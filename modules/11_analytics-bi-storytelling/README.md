# Module 11 · Analytics, BI & storytelling

**Roles:** DA · all · **Size:** 2 weekends · **Priority:** P0 for data analyst roles · **Builds:** Aerolisa M8 (analytics pack)

## Why this matters
Many Airbus data apprenticeships are analyst roles: "collect and prepare data from Skywise", "develop and harmonize management dashboards to centralize KPIs", with tools like Skywise, Google Sheets, SAP Analytics Cloud, Qlik Sense. I already build Power BI and PowerPoint visuals at ALTEN; this module turns that experience into a method and a public proof.

## 🎯 Apprenticeship level (must)
- [ ] KPI design: definition, formula, grain, filters, owner, target; leading vs lagging indicators
- [ ] Aviation KPIs: on-time performance, delay minutes by cause, dispatch reliability, utilization (hours and cycles per day), deliveries and backlog, unscheduled removal rate
- [ ] Dashboard design: one question per page, chart choice, pre-attentive attributes, decluttering, accessible colors, mobile/print constraints
- [ ] Power BI: Power Query, star-schema data model, relationships, DAX basics (`CALCULATE`, filter context, `SUMX`, time intelligence), measures vs calculated columns
- [ ] Google Sheets / Excel advanced: pivot tables, `XLOOKUP`, `QUERY` (Sheets), data validation, charts
- [ ] Streamlit + Plotly for app-style analytics
- [ ] Insight writing: answer first (pyramid principle), "so what", one recommendation; a 1-page memo
- [ ] Presenting to stakeholders in 3 minutes; handling "why does this number differ from mine?"
- [ ] Awareness of BI tools seen at Airbus: Qlik Sense, SAP Analytics Cloud, Looker Studio; Foundry's own Contour/Quiver/Workshop dashboards

## 🚀 Pro level
- [ ] Microsoft PL-300 certification
- [ ] Row-level security in Power BI; incremental refresh
- [ ] An analysis built entirely in Contour + Notepad report in Foundry

## Steps
**Weekend 1: KPIs and analysis**
1. Learn: *Storytelling with Data* chapters 1–6 (commute-friendly); Eurocontrol performance data documentation.
2. Practice: define 8 KPIs for "European operations" and "Airbus production" in a KPI dictionary (`work/kpi-dictionary.md`).
3. Apply: Aerolisa M8 steps 1–4 (ingest Eurocontrol + Airbus orders & deliveries, SQL analyses).

**Weekend 2: dashboard and memo**
4. Learn: Microsoft Learn PL-300 modules on data modeling and DAX (only the core ones).
5. Practice: Power BI report on the same data (or Streamlit if no Windows machine); then the 1-page insight memo.
6. Apply: Aerolisa M8 steps 5–7 (dashboard, memo, 3-minute recorded presentation).

## Exit test (90 min, no AI)
From an unseen operations dataset: 3 KPIs defined, a 2-page dashboard, a 1-page memo with one recommendation. Then a 3-minute presentation recorded and rewatched.
