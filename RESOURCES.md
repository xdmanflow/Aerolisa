# Resources

Free first. One main resource per topic; the rest is backup. Module READMEs say which chapter or course to use when.

## Python & software
- Python official tutorial (docs.python.org) · *Python for Data Analysis*, 3rd ed., Wes McKinney (free online at wesmckinney.com/book)
- pandas user guide · NumPy user guide · pytest docs
- MIT *The Missing Semester* (missing.csail.mit.edu): shell, Git, tooling

## SQL
- SQLBolt (interactive basics) · LeetCode *SQL 50* study plan · DataLemur SQL questions
- DuckDB docs · PostgreSQL docs (window functions chapter)

## Data engineering
- *Fundamentals of Data Engineering*, Reis & Housley (book): lifecycle, architecture
- *The Data Warehouse Toolkit*, Kimball (book): dimensional modeling, chapters 1–3
- DataTalksClub *Data Engineering Zoomcamp* (free, GitHub)
- Apache Spark docs: PySpark API, Spark SQL, tuning guide
- pandera docs (data validation) · Apache Airflow docs (concepts)

## Palantir Foundry & AIP
- Developer Tier, free: build.palantir.com (availability depends on country)
- Palantir Learn: learn.palantir.com (speedruns, deep dives, tracks, exam guides)
- Foundry documentation: palantir.com/docs/foundry
- Palantir Developer Community: community.palantir.com
- Palantir Developers YouTube channel
- Full path: [palantir/README.md](palantir/README.md)

## Statistics & probability
- *OpenIntro Statistics* (free PDF) · *Think Stats*, Allen Downey (free)
- StatQuest (YouTube) · Khan Academy statistics
- lifelines docs (survival analysis)

## Machine learning
- *An Introduction to Statistical Learning with Python* (ISLP, free at statlearning.com)
- scikit-learn user guide · XGBoost and LightGBM docs · SHAP docs
- *Mathematics for Machine Learning*, Deisenroth et al. (free at mml-book.github.io)
- 3Blue1Brown: *Essence of Linear Algebra*, *Neural Networks*
- Kaggle Learn micro-courses (Intermediate ML, Feature Engineering)

## Time series, predictive maintenance, deep learning
- *Forecasting: Principles and Practice*, Hyndman & Athanasopoulos (free online): concepts
- NASA Prognostics Center of Excellence data repository (C-MAPSS)
- Saxena et al., *Damage Propagation Modeling for Aircraft Engine Run-to-Failure Simulation* (PHM 2008): the C-MAPSS paper
- PyTorch tutorials · Karpathy, *Neural Networks: Zero to Hero*

## MLOps, cloud, APIs
- *Made With ML*, Goku Mohandas (free) · DataTalksClub *MLOps Zoomcamp*
- Docker docs (get started) · GitHub Actions docs · FastAPI tutorial · MLflow docs
- AWS Skill Builder: *Cloud Practitioner Essentials* (free)

## GenAI
- Hugging Face LLM course (free)
- Prompt engineering guides from the major LLM providers' documentation
- DeepLearning.AI short courses (RAG, agents, evaluation)
- Palantir AIP documentation and the AIP speedruns on Palantir Learn

## Analytics & BI
- Microsoft Learn: PL-300 Power BI learning path (free)
- *Storytelling with Data*, Cole Nussbaumer Knaflic (book)
- Streamlit docs · Plotly docs

## Aerospace domain
- FAA *Aviation Maintenance Technician Handbooks*: General, Airframe, Powerplant (free, public domain)
- EASA: overview pages on Part-M, Part-145, Part-CAMO, Part-21 (easa.europa.eu)
- Airbus newsroom and Skywise pages (aircraft.airbus.com, Skywise section)
- Eurocontrol Aviation Intelligence Portal / ansperformance.eu (operations data and reports)
- OpenSky Network docs (ADS-B, REST API)

## Interviews & career
- careers.airbus.com · Airbus "reward and benefits" and "our values" pages
- DataLemur and StrataScratch (data interview questions)
- *Ace the Data Science Interview*, Huo & Singh (book)
- Career folder: [career/](career/README.md)

## English
- ETS official TOEIC Listening & Reading preparation material
- BBC Learning English · English podcasts on the commute (aviation and tech)
