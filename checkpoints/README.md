# Exit tests

Every module ends with an exit test, described in its README. Rules:

- Closed book, no AI, timed. Documentation lookup allowed only where the test says so (as in a real job).
- Pass mark: **80%**. Below it: open a `gap` issue per mistake, redo the gaps, retake the failed part.
- Log every attempt, including failed ones. The log is part of the portfolio of honesty.
- Store the test, my answers and the correction in `modules/NN/work/exit-test/`.
